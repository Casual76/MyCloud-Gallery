# Fase 8 (P10, E-Q5): i refusi dei nomi. Conservativi: un nome l'ha scelto l'utente, correggere un'altra parola nel nome sbagliato e' peggio che non correggere.
# Da cinque lettere, la stessa iniziale, una modifica sola, un solo nome possibile, mai solo l'ultima lettera ("Chiaro" non e' Chiara, "Paola" non e' Paolo); si corregge
# una lettera scambiata con la vicina, raddoppiata o tolta dal raddoppio, una "k" per una "c" e, da sette lettere in su, una lettera qualunque. "Nome cercato<-scritto".

# --- Un nome scritto male
Marko => N Marco #1 any word=marko alt=parola:marko => - => - => - => Marco<-marko
Marcoo => N Marco #1 any word=marcoo alt=parola:marcoo => - => - => - => Marco<-marcoo
Giulai => N Giulia #1 any word=giulai alt=parola:giulai => - => - => - => Giulia<-giulai
Elana => - => Elana => elana
